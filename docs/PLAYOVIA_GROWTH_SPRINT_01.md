**Secondary markets:** United Kingdom, Canada, Australia

This is a practical publishing kit, not a traffic guarantee. Do not buy followers, use engagement pods, spam communities, or promise game features that a specific title does not support.

## 2. One original video, three platform posts

Create one clean 9:16 master video per day (1080×1920, MP4). Export without another platform's watermark. Post the original file separately to YouTube Shorts, TikTok and Instagram Reels. Add platform-native text/audio where useful and ensure the gameplay shown is real and from the named game.

Start with one strong post per day across all three platforms. YouTube says there is no minimum Shorts posting cadence; viewer choice, retention and satisfaction matter more than hitting an arbitrary volume target.

Suggested edit:
- 0–2 seconds: show the most surprising gameplay moment and a short hook.
- 2–15 seconds: show the challenge clearly; cut dead time.
- Final 2–4 seconds: ask a simple question and show Playovia branding / site URL.
- Keep captions readable and avoid covering important gameplay controls.

## 4. Search and SEO sprint

The site already has a general games landing page at /free-online-games.html and a sitemap listing the catalogue. Prioritize useful, game-specific pages only when the page can offer original details, accurate instructions, controls, screenshots or clips, and a clear play link.

Suggested page candidates to validate before publishing:
1. Flag Frenzy — flag quiz / geography guessing game.
2. Scribble Party — online drawing and guessing with friends (describe multiplayer only as supported by the live game).
3. Obby Rush — browser parkour challenge.
4. Riftbound — logic puzzle game.
5. Dungeon Hunter — browser action adventure.

For every page:
- One clear search intent and a unique title / meta description.
- Original description, controls, device notes and useful tips verified against the actual game.
- Prominent play link and links to 2–3 genuinely related games.
- Canonical URL, indexable status, and inclusion in sitemap only after the page is live.
- No copied descriptions, keyword stuffing, fake reviews, or made-up ratings.

### Weekly SEO checks
- Search Console: indexing status and query impressions for the home page and /free-online-games.html.
- Inspect important game URLs individually if they are not indexed.
- Review mobile usability and page loading issues.
- Check that each internal link opens the correct live game.
- Keep the sitemap accurate; do not add URLs that return errors or redirects.

## 5. Measurement sheet

Record each post after 24 hours and again after 7 days:

| Metric | Why it matters |
|---|---|
| Views / reach | Distribution |
| Average watch time / retention | Whether the video holds attention |
| Shares and saves | Whether viewers found it worth passing on |
| Profile visits | Brand interest |
| Website link clicks | Traffic intent |
| Landing page sessions by UTM | Actual site visits attributed to a post |
| Game starts / return visits | Whether visitors actually play and return |

Do not judge a post only by views. Repeat the strongest topic and hook style after comparing retention, shares and website sessions.
